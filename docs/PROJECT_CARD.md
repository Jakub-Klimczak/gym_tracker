# gym_tracker

**Approval date:** 2026-10-20

## Description

gym_tracker helps you track your gym goals, bring personal activity data from
smartwatches into one place, and estimate calories from food photos with a
generative AI API.

## Features

- Track workouts, progress, and personal fitness goals.
- Import activity data from compatible smartwatches.
- Estimate meal calories from images using AI.
- Review activity and nutrition insights in one place.

## UI

A simple, mobile-first dashboard for daily activity, workout progress, and
nutrition, with quick access to photo-based calorie estimates and goal tracking.
